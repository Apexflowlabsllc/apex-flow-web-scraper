# Contributing

Open an issue describing the observed behavior, expected behavior and a minimal
public or synthetic fixture. Do not include private URLs, credentials or collected
personal data. Keep pull requests focused and include meaningful regression
coverage for behavior changes. Run `python -m pytest -q` before submitting.

Describe whether a browser is required and whether a proposed dependency makes
an external service mandatory. The core must remain usable without a paid
scraping account or model key. Contributions are under the repository MIT license.
