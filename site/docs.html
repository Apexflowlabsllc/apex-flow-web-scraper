Apex Flow Web Scraper

Build with clean web data.

A straightforward HTTP API for public pages, documents and AI-ready Markdown.

Get an API key →

1. Authenticate

Send your key in the Authorization: Bearer YOUR_API_KEY header. Keep it on your server. Do not embed it in a public website or mobile app.

2. Scrape a page

curl https://webscraper.apexflowlabs.com/v1/scrape \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","render":"never"}'

The response contains result.markdown, result.text, result.title, source metadata and a retrieval receipt, plus credits_used and credits_left.

Request options

OptionMeaning
urlRequired public HTTP or HTTPS URL; ports 80/443 only.
rendernever (1 credit), auto (1–3), or always (3). Default: auto.
chunksText chunk size for RAG. Example: 1000.
screenshotBoolean; renders the page and returns screenshot_png_base64.
wait_selectorCSS selector to wait for when rendering.
max_ageCache age in milliseconds; 0 requests a fresh fetch.

Python

import json, urllib.request
request = urllib.request.Request(
    "https://webscraper.apexflowlabs.com/v1/scrape",
    data=json.dumps({"url": "https://example.com", "render": "never"}).encode(),
    headers={"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"},
)
with urllib.request.urlopen(request, timeout=100) as response:
    print(json.load(response)["result"]["markdown"])

Extract named fields without an AI model

Add a recipe to a scrape request. Fields are returned in result.data at no additional credit cost.

{"url":"https://example.com","render":"never","recipe":{"fields":{"heading":{"selector":"h1","required":true}}}}

Discover URLs

POST /v1/map with the body below. One credit per successful map call; empty results are free. Up to 1,000 URLs and 20 sitemap files, with a 45-second deadline. Sitemap requests also honor robots.txt.

{"url":"https://example.com","limit":1000}

Scrape a batch

POST /v1/batch with 1–10 URLs and the same scrape options. Each result has its own status and credit count. The 80-second batch deadline returns any unprocessed URLs so you can retry them. Successful pages cost the usual 1 or 3 credits.

{"urls":["https://example.com","https://example.org"],"render":"never"}

Search your saved pages

POST /v1/search to search up to your latest 100 successfully scraped URLs. This searches your account’s saved text, not the open web. Search uses no credits.

{"query":"documentation"}

Check usage

curl https://webscraper.apexflowlabs.com/v1/usage \
  -H "Authorization: Bearer YOUR_API_KEY"

Limits and errors

Paid accounts may make 60 API requests per minute; free accounts may make 30. This shared limit includes credit-free search and usage requests. Batch pages also count toward the scrape limit. Each account may run 2 scrapes concurrently. Scrapes have a 90-second deadline and a 256 KiB response limit. Each billing period permits at most twice the included credit allowance in scrape/map attempts, including failures. Contact support if repeated source failures exhaust this protection limit. The service also applies a shared concurrency cap; retry a 429 response after the Retry-After interval.

StatusAction
400Check the URL and options. A blocked or disallowed source may also return 400.
401Use a valid API key.
402Check your credits or subscription in the dashboard.
429Wait before retrying; use exponential backoff.
502 / 503 / 504Temporary failure. Retry with backoff. Failed scrapes return reserved credits.

Hosted versus self-hosted

The hosted API supports single-page and 10-URL batch scraping, sitemap discovery, deterministic CSS extraction, account-scoped saved-page search, Markdown/text, PDF/DOCX, rendering, screenshots and chunks. The open-source edition additionally supports local search, sitemap discovery, crawl jobs, change tracking and extraction with your own supported model provider. The Node SDK currently targets the local workspace; use HTTP for the hosted API.

Responsible collection

Only submit public URLs you are authorized to collect. We honor robots.txt and do not bypass login requirements, CAPTCHAs or bot walls. Do not put credentials or personal information in URLs.
