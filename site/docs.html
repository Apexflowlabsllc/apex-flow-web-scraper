Other MCP clients

For a client with local MCP server support, install the adapter in a Python 3.11+ environment:

python -m pip install "git+https://github.com/Apexflowlabsllc/apex-flow-web-scraper.git"

Set APEX_SCRAPER_API_KEY in your client’s secret environment. Configure a stdio server with the command apex-scraper-mcp from that environment. The hosted service runs the browser. The hosted server and the adapter expose six tools:

  • scrape_page returns Markdown, source receipts, optional CSS fields and RAG chunks.
  • scrape_batch reads up to ten URLs in parallel and reports which succeeded.
  • check_changes re-reads up to ten URLs and returns only what changed since your last read.
  • map_site discovers public sitemap URLs.
  • search_saved finds text in the pages you have already scraped: the latest 100 on a trial, 1,000 on paid plans.
  • credit_balance returns credits, plan limits, renewal date and recent usage.

Start by asking the agent to check its credit balance, then scrape one public page. Standard API credits and limits apply.

1. Authenticate

Send your key in the Authorization: Bearer YOUR_API_KEY header. Keep it on your server. Do not embed it in a public website or mobile app.

2. Scrape a page

curl https://webscraper.apexflowlabs.com/v1/scrape \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","render":"never"}'

The response contains result.markdown, result.text, result.title, source metadata and a retrieval receipt, plus credits_used, credits_left and change.

Request options

OptionMeaning
urlRequired public HTTP or HTTPS URL; ports 80/443 only.
rendernever (1 credit), auto (1–3), or always (3). Default: auto.
chunksText chunk size for RAG. Example: 1000.
screenshotBoolean; renders the page and returns screenshot_png_base64.
wait_selectorCSS selector to wait for when rendering.
max_ageCache age in milliseconds; 0 requests a fresh fetch.
pagePart of a long document to return, starting at 1. See Long documents.
max_tokens200–60000. Returns the page in parts that each fit this budget. See Fit a context budget.
fallback"archive" reads the latest Internet Archive copy when the live site refuses. See Archive fallback.

Python

import json, urllib.request
request = urllib.request.Request(
    "https://webscraper.apexflowlabs.com/v1/scrape",
    data=json.dumps({"url": "https://example.com", "render": "never"}).encode(),
    headers={"Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json"},
)
with urllib.request.urlopen(request, timeout=100) as response:
    print(json.load(response)["result"]["markdown"])

Extract named fields without an AI model

Add a recipe to a scrape request. Fields are returned in result.data at no additional credit cost.

{"url":"https://example.com","render":"never","recipe":{"fields":{"heading":{"selector":"h1","required":true}}}}

Discover URLs

POST /v1/map with the body below. One credit per successful map call; empty results are free. Up to 1,000 URLs and 20 sitemap files, with a 45-second deadline. Sitemap requests also honor robots.txt.

{"url":"https://example.com","limit":1000}

Scrape a batch

POST /v1/batch with 1–10 URLs and the same scrape options. Pages run in parallel: six at once on paid plans and two on a trial. Results come back in the order you sent the URLs, each with its own status, credit count and change status. The reply reports concurrency and duration_ms. The 80-second batch deadline returns any unprocessed URLs so you can retry them. Successful pages cost the usual 1 or 3 credits.

{"urls":["https://example.com","https://example.org"],"render":"never"}

Search your saved pages

POST /v1/search to search the pages you have already scraped: your latest 100 on a trial and your latest 1,000 on any paid plan. This searches your account’s saved text, not the open web. Search uses no credits. limit accepts 1–25 results.

{"query":"documentation","limit":10}

Long documents

A response holds up to 256 KiB. A longer document, such as a full specification or a long report, is returned in consecutive parts instead of failing. The reply includes pagination with page, pages and next_page. Request the next part with the same options plus "page". Parts are cut on line breaks, so headings, tables and code blocks stay whole lines. Each part is a normal request at the usual credit price; send max_age to reuse the fetch.

{"url":"https://www.rfc-editor.org/rfc/rfc9110.html","render":"never","outputs":["markdown"],"max_age":3600000,"page":2}

Fit a context budget

Every scrape reply includes estimated_tokens for the text it returned, counted as four characters per token. Set max_tokens to receive a page in consecutive parts that each fit your model’s budget. Parts are cut on line breaks and joined parts reproduce the page exactly. Follow pagination.next_page as with long documents.

{"url":"https://en.wikipedia.org/wiki/Web_scraping","render":"never","outputs":["markdown"],"max_tokens":2000}

Archive fallback

Some sites refuse automated readers, return an error, or have removed the page. We do not disguise requests, rotate addresses or solve CAPTCHAs. When a live read fails for one of those reasons, the error carries a hint. Send the request again with "fallback":"archive" and we return the most recent public copy held by the Internet Archive’s Wayback Machine.

{"url":"https://www.zillow.com/","render":"never","outputs":["markdown"],"fallback":"archive"}

An archived result is always labelled. result.archive states captured (when the copy was taken), snapshot_url, the reason the live read failed and live_page_served: false; result.warnings includes archived_copy. Archived content can be out of date, so check captured before relying on prices, stock or news. A page that reads normally is never replaced by an archive copy. The usual 1 credit applies when a copy is returned; when none exists you get the original error at no charge. Site owners can ask the Internet Archive to exclude their pages.

Track what changed

Every scrape compares the page with the copy your account read last time and adds a change object: status is new, unchanged or changed, with the content hash and the time of your previous check. To monitor a page, add "diff" to outputs. You receive the source receipt and the changed lines without the page body, so a monitoring agent spends context only on what moved. The usual 1 or 3 credits apply. History is private to your account and covers your saved pages.

{"url":"https://example.com/pricing","render":"never","outputs":["diff"]}
{"credits_used":1,"credits_left":24990,
 "change":{"status":"changed","previous_check":1794500000.0,
   "diff":"--- previous\n+++ current\n@@ -3 +3 @@\n-Price: $10\n+Price: $12"},
 "result":{"url":"https://example.com/pricing","receipt":{}}}

Send the same option to /v1/batch to check ten pages in one call. MCP clients use check_changes.

Choose what goes into your agent’s context

Set outputs on a scrape or batch request to return just the content your agent uses. For reading, request ["markdown"]. For a CSS recipe, request ["data", "evidence"]. For retrieval, request ["chunks"]. The response retains available source receipts and validation warnings. The same credit price applies.

Check usage

curl https://webscraper.apexflowlabs.com/v1/usage \
  -H "Authorization: Bearer YOUR_API_KEY"

Returns credits_left, credits_total, plan, period_end, your limits, the number of saved pages, and daily credits and requests for the last 14 days. Every API response also carries X-Credits-Remaining, X-RateLimit-Limit, X-RateLimit-Remaining and an X-Request-Id you can quote to support.

Limits and errors

Paid accounts may make 60 API requests per minute; free accounts may make 30. This shared limit includes credit-free search and usage requests. Batch pages also count toward the scrape limit. Paid accounts may send up to six page scrapes concurrently. Free trials allow two. The hosted service accepts eight active page scrapes in total and runs up to two browser renders at once. Other admitted renders wait within the request deadline. Requests to the same host follow its crawl delay. Scrapes have a 90-second deadline. Responses hold 256 KiB; longer documents are returned in parts. Each billing period permits at most twice the included credit allowance in scrape/map attempts, including failures. Contact support if repeated source failures exhaust this protection limit. The service also applies a shared concurrency cap; retry a 429 response after the Retry-After interval.

Every error is JSON with a readable error, a stable code and retryable. A 402 includes credits_left and a buy_url; a 429 includes retry_after in seconds. MCP tool errors carry the same fields, so an agent can decide to retry, stop, or show the purchase link to its user.

{"error":"needs up to 1 credits, 0 left","code":"insufficient_credits","retryable":false,
 "credits_left":0,"buy_url":"https://webscraper.apexflowlabs.com/#pricing"}

Hosted versus self-hosted

The hosted API supports single-page and parallel 10-URL batch scraping, change tracking with diffs, sitemap discovery, deterministic CSS extraction, account-scoped saved-page search, Markdown/text, PDF/DOCX, rendering, screenshots and chunks. The open-source edition additionally supports local search, sitemap discovery, crawl jobs, change tracking and extraction with your own supported model provider. The Node SDK currently targets the local workspace; use HTTP for the hosted API.

Responsible collection

Only submit public URLs you are authorized to collect. We honor robots.txt and do not bypass login requirements, CAPTCHAs or bot walls. Do not put credentials or personal information in URLs.
