What you get

Everything a scraper should do, owned.

Markdown that keeps its shape

Headings stay headings, tables become real tables, code keeps its language, cookie banners and navigation are removed.

JS pages, rendered safely

Warm isolated browser with every request routed through our guarded fetcher. Hidden elements stripped. Screenshots on request.

PDF, DOCX, feeds, JSON

One call for every document type, with unpack limits that stop zip bombs.

Site map and crawl

Reads robots.txt, nested and gzip sitemaps, then page links. Durable jobs survive restarts.

Owned search

Every page you scrape is indexed in SQLite FTS5 with BM25 ranking and highlighted snippets. No search vendor.

Schema extraction

JSON Schema in, validated JSON out, using DeepSeek first and OpenRouter second. Your key, your data.

Change tracking

Content-hash comparison against the last scrape, with a readable diff.

Agent ready

MCP tools for fetch, map, crawl, search and compare. Page text is treated as untrusted data.

Polite by default

robots.txt, Crawl-delay, per-host pacing, retry with Retry-After, public-address-only fetching.

Straight talk

What we do not claim.

We do not solve CAPTCHAs or evade bot walls: zillow.com and glassdoor.com still block us, and robots.txt-disallowed pages stay unread. Our search covers the sites you index, not the whole web. Rendered pages take 4 to 5 seconds. Schema extraction is tested against a mock model and not yet measured live. There is no Node SDK yet.
