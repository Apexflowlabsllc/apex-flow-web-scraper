Before you build

A few good questions.

What happens after I sign up?

Free access opens directly in your browser. For purchases, Stripe returns you to your access page after payment. Copy your API key there and keep it safe. Open the dashboard to see your credits or scrape your first page.

What counts as a credit?

A standard page costs 1 credit. A page rendered in Brave, including screenshots, costs 3. The API reserves the maximum possible cost first and refunds unused credits. Failed scrapes are not charged.

Can I cancel my subscription?

Yes. Open your dashboard, enter your API key and choose Manage billing. Stripe lets you cancel at the end of your paid period and download invoices.

Can it scrape every website?

No. Crawls obey robots.txt, and a page you name is read on your request. We do not bypass CAPTCHAs, paywalls or bot walls; a refused page comes back as a labelled archive copy. Our benchmark returned 26 of 30 URLs. Use the free trial to check the public sources your project needs.

Can I use this for RAG?

Yes. Send a public URL and a chunks option to get clean Markdown and text chunks. You choose your own embedding model and vector database.

Do I need to install anything?

No for the hosted API: any HTTP client works. The self-hosted edition needs Python 3.11 or later, and Brave for rendered pages.

Straight talk

What we do not claim.

We do not solve CAPTCHAs or evade bot walls. Sites behind bot walls, such as glassdoor.com, still block live reads; we return a dated Internet Archive copy instead, and it can be days or years old. Our search covers the pages you have read, not the whole web. Rendered pages take 4 to 5 seconds. AI extraction returns valid JSON but can get a field wrong, so check results. The Python and Node clients are in the GitHub repository and are not yet on PyPI or npm. Every number on this page comes from BENCHMARK-2026-11-05.md.

Questions

Answers before you sign up.

What is Apex Flow Web Scraper?

A hosted API and MCP server that turns public web pages, PDFs and DOCX files into clean Markdown for developers and AI agents. It can read one page, a batch, or crawl a whole site, and it reports what changed since your last read.

How much does it cost?

You start with 1,000 free credits. After that it is $5 once for 35,000 credits, or $15, $79 or $299 a month for 110,000, 850,000 or 3,750,000 credits. A plain page costs 1 credit and a rendered page costs 3. Failed and blocked pages cost nothing and there are no automatic overage charges.

How is it different from Firecrawl?

It has a $5 one-time option, reports change status on every read, splits pages to fit a token budget, and returns a dated archive copy when a live site refuses. It does not disguise requests or use proxies to get past bot walls, so Firecrawl reads some live pages that we do not; for those we return a labelled archive copy.

Can my AI agent use it?

Yes. Connect any MCP client to https://webscraper.apexflowlabs.com/v1/mcp with your API key. There are 19 hosted MCP tools for scraping, batches, change checks, scheduled monitors, site maps, crawls, data packages, store tracking, saved-page search and credits, plus optional whole-web search. Errors tell the agent whether to retry and where to add credits.

Does it get past CAPTCHAs and bot walls?

No. It does not solve CAPTCHAs, disguise requests or rotate addresses. When a live site refuses, you can ask for the most recent Internet Archive copy, which is labelled with its capture time.

What happens when I run out of credits?

Requests return an error with a link to buy more. Nothing is charged automatically. The one-time pass and the monthly plans are on the pricing section of this page.
