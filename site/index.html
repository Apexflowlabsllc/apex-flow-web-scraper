Start

One line. No account.

# Install (Python 3.11+)
pip install "git+https://github.com/Apexflowlabsllc/apex-flow-web-scraper.git"

# Python
from rainbo_scrape import scrape, map_site
page = scrape("https://docs.python.org/3/", max_age=3600000)
print(page.markdown)           # headings, GFM tables, fenced code with language
urls = map_site("https://example.com")["urls"]   # sitemaps (indexes, gzip) + links

# Command line
rainbo-scrape fetch https://example.com
rainbo-scrape index https://example.com/ && rainbo-scrape search "pricing"

What you get

Everything a scraper should do. Owned.

01

Markdown that keeps its shape

Headings stay headings, tables become real tables, code keeps its language. Cookie banners and navigation are removed.

02

JS pages, rendered safely

A warm isolated browser with every request routed through our guarded fetcher. Hidden elements stripped, screenshots on request.

03

PDF, DOCX, feeds, JSON

One call for every document type, with unpack limits that stop zip bombs.

04

Site map and crawl

robots.txt, nested and gzip sitemaps, then page links. Jobs survive restarts.

05

Owned search

Every page you scrape is indexed in SQLite FTS5 with BM25 ranking. No search vendor.

06

Schema extraction

JSON Schema in, validated JSON out via DeepSeek then OpenRouter.

07

Change tracking

Content-hash comparison with a readable diff.

08

Agent ready

MCP tools for fetch, map, crawl, search and compare. Page text is treated as untrusted data.

09

Polite by default

robots.txt, Crawl-delay, per-host pacing, retry with Retry-After, public-address-only fetching. The rules are the product.

10

Open-web crawl

Seed a URL and follow links across public sites, up to 1,000 pages a job. Built, not yet run at scale.

Straight talk

What we do not claim.

We do not solve CAPTCHAs or evade bot walls. zillow.com and glassdoor.com still block us, and robots.txt-disallowed pages stay unread. Our search covers the sites you index, not the whole web. Rendered pages take 4 to 5 seconds. Schema extraction is tested against a mock model, not yet measured live. The Node SDK exists but is not published yet. Every number on this page comes from BENCHMARK-2026-11-05.md.
