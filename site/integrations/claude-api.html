Web scraping for Claude API.

Pass the scraper to a Messages API call; Claude calls the tools itself. Your assistant gets 14 tools for reading pages as clean Markdown, crawling sites, tracking changes and searching what it has read.

  1. Get a key

    1,000 free credits, no card, no email. Open the free trial, save the key, and put it in an environment variable named APEX_SCRAPER_API_KEY.

  2. Python

    import os, anthropic

client = anthropic.Anthropic()
response = client.beta.messages.create(
    model="claude-opus-5-5",
    max_tokens=2000,
    messages=[{"role": "user", "content": "Read https://example.com and summarise it in three points."}],
    mcp_servers=[{
        "type": "url",
        "url": "https://webscraper.apexflowlabs.com/v1/mcp",
        "name": "apex-scraper",
        "authorization_token": os.environ["APEX_SCRAPER_API_KEY"],
    }],
    tools=[{"type": "mcp_toolset", "mcp_server_name": "apex-scraper"}],
    betas=["mcp-client-2025-11-20"],
)
print(response.content)

  3. Try it

    • Read https://example.com/pricing and list the plans as a table.
    • Map docs.example.com, then read the five pages about authentication.
    • Check these three pages again and show me only what changed.
    • What has the house price trend been in Sacramento, CA over five years?

The connector sends your scraper key as the bearer token on each call.

Questions

What does it cost?

A plain page is 1 credit and a rendered page is 3. The free trial is 1,000 credits once, with no card. After that it is $5 once for 35,000 credits or $15 a month for 110,000. Failed pages return their credits and there are no automatic overage charges.

Where do I get the key?

At webscraper.apexflowlabs.com/trial.html. The key is shown once in your browser, so save it in a password manager and put it in an environment variable or your tool's secret store.

What will it not do?

It does not solve CAPTCHAs, rotate proxies or disguise requests. Crawls obey robots.txt and Crawl-delay. A page that refuses a live read comes back as a dated Internet Archive copy, labelled as such.
