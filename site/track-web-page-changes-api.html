How-to

How to track changes on a web page with an API.

Scrape the page on a schedule. Each result tells you whether it is new, unchanged or changed, and can return only the lines that moved.

curl https://webscraper.apexflowlabs.com/v1/scrape \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/pricing","render":"never","outputs":["markdown","diff"]}'

When the page changed, the response includes a unified diff such as:

--- previous
+++ current
@@ -3 +3 @@
-Price: $10
+Price: $12

Run it from a scheduler of your choice and alert on changed. Pages you scrape are also saved to a searchable index in your account.

Limits to know

  • It compares the text it reads, not screenshots.
  • It obeys robots.txt and does not solve CAPTCHAs or evade bot walls.
  • Credit cost per scrape applies: 1 plain, 3 rendered; failures are refunded.
