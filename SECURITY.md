# Security reporting

Do not publish credentials or private collected content in issues. Report a
suspected vulnerability to hello@apexflowlabs.com with reproduction steps and
the affected version. No response-time commitment is offered for this early release.

Keep the workspace private. Do not expose it directly to the public internet.
Use supported Python/dependency versions and review source-page content as
untrusted input. This release is not a hardened multi-tenant service.
